    03 / A failure improved the scorer

    Recorded counterexample retained

    An earlier endpoint-only check passed a cube that slipped during transfer but landed near its target. Scorer v3 rejects that trace. The regression suite checks the real failure and the corrected nominal carry.

    Checks are sampled every 50 ms: both jaw contacts during hold/carry, sufficient lift, supported lowering, and stable release within 25 mm of the target. Events between samples can be missed; this is not continuous formal verification.
